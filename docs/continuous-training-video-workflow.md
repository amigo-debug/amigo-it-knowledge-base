# 連續圖像培訓影片工作流程

## 目的

當需要以生成式媒體製作程序培訓短片時，最常見的問題不是畫面不夠漂亮，而是**物件結構、角色姿勢與前後鏡頭不一致**。建立可重用的主參考圖，並以該圖延伸後續畫面，可顯著減少角色、器材及場景跳變。

## 建議流程

| 階段 | 做法 | 原因 |
|---|---|---|
| 1. 定義製作規格 | 先確認比例、畫面風格、旁白聲線、字幕語言及音樂策略。 | 避免完成多張素材後才發現播放場景或視覺風格不合用。 |
| 2. 先出一張主參考圖 | 主圖要清楚展示人物全身、主要器材的完整結構、接觸位置及環境。 | 後續鏡頭可沿用相同的角色與器材錨點。 |
| 3. 逐張確認關鍵姿勢 | 先確認主圖，再產生操作、觀察、異常處理等連續圖。 | 將錯誤修正控制在單張圖階段，避免整段影片重做。 |
| 4. 先用靜態圖建立時間線 | 將關鍵圖與短動態鏡頭按培訓順序編排，並加入字幕。 | 讓複雜程序能以短片節奏清楚呈現。 |
| 5. 用分段旁白同步 | 以每個鏡頭區間生成獨立旁白檔，而非整段影片一次過朗讀。 | 可調整個別段落速度，避免旁白覆蓋錯誤畫面。 |
| 6. 最後再加低音量音樂 | 背景音樂必須明顯低於旁白，且不應有突然轉折。 | 程序教學的語音清晰度永遠優先。 |

## 主參考圖的驗收清單

> 只有主參考圖通過以下檢查，才應延伸後續連續圖。

| 檢查面向 | 必須確認的問題 |
|---|---|
| 人體結構 | 人物有沒有完整肢體？手、腳與接觸物件的位置是否合理？ |
| 器材結構 | 器材的支架、輪子、固定點、踏板或枱板是否完整，而且符合現實使用方式？ |
| 坐姿／站姿 | 身體有沒有真正坐入椅內或站在地面上？承托位置是否合理？ |
| 操作安全 | 餐具、輔具或操作工具是否處於合理位置，沒有誤導性的危險姿勢？ |
| 鏡頭可讀性 | 觀眾能否一眼看到重要動作、面部表情與主要器材？ |
| 延續性 | 角色服裝、髮型、器材顏色、房間及光線可否在下一鏡頭維持一致？ |

## 直向微學習影片的節奏

對於約三分鐘的直向程序短片，一個可行的結構是：開首說明與注意事項、準備、核心操作、觀察／等待、異常處理、餐後或收尾步驟、重點回顧。短片宜用作複修及提示；涉及安全、臨床判斷或實際操作技能的內容，仍須配合現場示範與稽核。

## 常用術語

| 術語 | 說明 |
|---|---|
| 主參考圖（master reference image） | 作為所有後續畫面一致性錨點的第一張確認圖。 |
| 連續圖像（continuous image sequence） | 在角色、場景和器材維持一致的前提下，展示不同步驟的一組圖片。 |
| 圖生影片（image-to-video） | 以一張確認圖作為起始畫面，產生短動態鏡頭的方法。 |
| 分段旁白（segmented narration） | 按鏡頭區段分開生成並放置的語音，而非一段長錄音。 |
| 燒錄字幕（burned-in subtitles） | 已直接寫入影片畫面的字幕，任何播放裝置都可看見。 |
| 媒體完整性檢核（media integrity check） | 檢查影片是否可讀取、比例、解析度、時長及聲音軌是否存在。 |
