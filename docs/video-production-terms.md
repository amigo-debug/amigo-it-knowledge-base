# 影片製作常用術語

本文只整理可重用的影片製作概念，適用於培訓、宣傳、教學及內部溝通短片；不包含任何特定機構、人物、個案、帳號、網址或系統資料。

## 影片分鏡圖（Video Storyboard）

分鏡圖是把一條影片拆成一格一格的畫面計劃。每格先寫清楚畫面內容、鏡頭、旁白、字幕和預計時間，再開始製作。這個做法的價值是先確認溝通邏輯，避免影片完成後才發現漏了重要步驟或次序錯誤。

> 可以把它想成出菜表：先決定每一道菜何時開始、何時完成，廚房才不會手忙腳亂。

## 影片關鍵畫面（Video Keyframe）

關鍵畫面是用來固定影片視覺基準的指定畫面。先確定人物的服裝、器材外觀、場景、光線和構圖，再以這個基準製作同一段或後續片段，可以減少角色外觀和物件款式在不同畫面突然改變的問題。

> 可以把它想成拍攝前先定好制服、髮型和背景；其後從不同角度拍攝，觀眾仍然會認得是同一個角色。

## 9:16 直式影片（9:16 Portrait Video）

9:16 是畫面闊度與高度比例為 9 比 16 的直式格式，適合手機全螢幕、即時通訊軟件、短片平台及直立式電子螢幕。製作時應預留上、下方安全區，避免字幕或關鍵訊息被播放器介面遮擋。

| 項目 | 建議 |
|---|---|
| 常見用途 | 手機、直立式螢幕、短片平台 |
| 畫面規劃 | 重要人物與器材放在中間安全區 |
| 字幕位置 | 避開最底部的播放器控制列 |
| 資訊密度 | 每一鏡只放一個主要行動或訊息 |

## 內嵌字幕（Burned-in Subtitles）

內嵌字幕是把字幕直接合成到影片畫面內，而不是另附一個字幕檔。無論觀眾用手機、電腦或電視播放，都會看到同一套字幕。重點是字幕需與旁白同步、字體足夠大、文字與背景有清晰對比，並把每句控制在容易閱讀的長度。

> 可以把它想成把安全提示直接印在海報上，而不是另派一張文字對照表給觀眾自己閱讀。

## 製作順序（Production Workflow）

一條需要內容準確、角色一致及字幕清楚的短片，建議按以下次序處理：先確認需求和分鏡，其後建立視覺參考與關鍵畫面，再生成或拍攝各段畫面；完成旁白與配樂後，才合成字幕並檢查時長、畫面比例和聲音清晰度。這個順序能把修改成本留在較早階段，避免後期大幅重做。

| 階段 | 主要目標 | 常見失誤 |
|---|---|---|
| 需求確認 | 明確受眾、目的、長度、語言和平台 | 未確認便直接生成，造成內容不合用 |
| 分鏡規劃 | 定義訊息次序、鏡頭和旁白 | 同一鏡放太多資訊，觀眾未能消化 |
| 視覺基準 | 固定角色、道具、服裝和場景 | 不同片段人物或器材外觀不一致 |
| 音訊與字幕 | 確保旁白、配樂及字幕節奏一致 | 背景音樂蓋過旁白或字幕過長 |
| 成片檢查 | 核對比例、時長、聲音及關鍵訊息 | 只看畫面美觀，沒有核對程序內容 |
